Lampa Torrent Assistant v0.1.0 (beta)

1. Requires Lampa with torrent source enabled and Tracker Rank v1.3.1 installed.
2. Add the JS URL to Lampa Plugins after publishing it via GitHub Pages.
3. The main Watch button routes to the native torrent list if the torrent source button exists.
4. The best score is cached from the last torrent list opened for this movie.
5. IMPORTANT: This beta does NOT query public parsers in the background when a card opens. Until you have visited the torrent list, it shows 'Торренты: ещё не проверены'.
6. It is a beta. The default play button binding may differ in custom Lampa builds.
7. If button navigation fails, disable the plugin. The existing Tracker Rank remains unchanged.
