# Lampa Tracker Rank v1.3.0 (beta)

Один JS-плагин для работы с публичными парсерами Jackett в Lampa. Для работы плагина не нужны отдельные контейнеры на NUC. Торрент воспроизводит существующий TorrServer.

## Функции

1. **Фильтр по трекерам:** RuTracker, Kinozal, Rutor, NNMClub, TorrentBy. Комбинированная раздача видна, если указан хотя бы один разрешённый сайт.
2. **Профили:** сбалансированный (по умолчанию), максимальное качество, быстрый запуск, экономия трафика.
3. **Разбор метаданных:** 4K/FHD/HD, HDR10/HDR10+/DV, HEVC/H.265, H.264, AV1, WEB-DL, WEBRip, Blu-ray, REMUX, TS/CAM.
4. **Осторожная группировка:** отключена по умолчанию, включается в настройках. Скрывает только предполагаемые дубликаты со схожими названием, форматом, русской озвучкой и размером. Для просмотра всех отключите группировку.
5. **Готовность к просмотру:** приблизительная оценка риска на основе числа сидов и битрейта. НЕ измерение скорости и НЕ гарантия отсутствия буферизации.
6. **Настройки Lampa:** отдельный раздел «Tracker Rank» при наличии SettingsApi (профиль, фильтр, сортировка, группировка, индикатор, оценка и каждый разрешённый трекер).

Дополнительно: распознавание русской дорожки (ДУБЛЯЖ, RUS, многоголосая) по заголовку и меткам; сортировка по оценке; единая цветная стилизация показателей битрейта, сидов и объёма вместо Torrent Styles v2.

## Веса рейтинга (Balanced)

- Разрешение — 30
- HDR / Dolby Vision — 10
- Русская озвучка — 25
- Тип релиза — 10
- Раздающие — 20
- Размер — 5
- Приоритет трекера — **0** (трекер влияет только на допуск в список)

Итого: **100**. Значения получаются по текстовым метаданным, а не по анализу видеофайла. Для неизвестного языка и размера используется умеренная, не максимальная оценка.

## Цвета

- **Битрейт:** <50 зелёный; 50–74.99 жёлтый; 75–99.99 янтарный; ≥100 красный.
- **Сиды:** <5 красный; 5–9 жёлтый; ≥10 зелёный.
- **Размер:** <25 ГБ зелёный; 25–49.99 жёлтый; 50–99.99 янтарный; ≥100 оранжевый.

## Ограничения бета-версии

- Плагин действует на DOM-карточки `.torrent-item`: другой шаблон Lampa может потребовать адаптации.
- Отображаемые статусы аудио, кодеков, форматов определяются эвристиками; маркировка раздачи бывает ошибочной или неполной.
- Сортировка может различаться между версиями Lampa и не гарантирована без теста на ТВ/пульте.
- Группировка консервативная, но иногда может ошибиться. По умолчанию выключена.
- Работа новых настроек требует `Lampa.SettingsApi` в данной сборке.
- При активной кешированной версии JS очистить кэш приложения или открыть ссылку с параметром `?v=13` (если сборка Lampa допускает).
